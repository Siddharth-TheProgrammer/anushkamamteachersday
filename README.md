# Anushka Ma'am's Tribute

Build a beautiful, warm, elegant, interactive Teachers’ Day website dedicated specifically to Anushka Ma’am, who teaches me Maths and Science.

This website is a personal digital Teachers’ Day gift from her student, Siddharth Yadav.

The website should feel like a combination of:

🌸 Greeting card

💌 Thank-you card

🏆 Appreciation page

📚 Life-lessons page

📋 Interactive student report card

📮 Interactive teacher complaint box

💖 Heartfelt Teachers’ Day message

🌷 Final thank-you card

The overall experience should feel genuinely personal, cute, warm, elegant, emotional, and memorable.

==================================================

IMPORTANT RELATIONSHIP & CONTENT RULES

The relationship must ALWAYS be described only as teacher and student.

Never use the words “bestie,” “best friend,” or “friend” anywhere on the website.

The website is exclusively for Anushka Ma’am.

Mention Anushka Ma’am naturally in several important sections.

Mention that she teaches me Maths and Science.

Do not compare Anushka Ma’am with any other teacher.

Do not say she is better than other teachers.

Do not include romantic language.

Do not include appearance-based compliments.

Do not describe her as “the cutest girl in the world” or anything similar.

Keep the emotional tone focused on gratitude, respect, trust, kindness, encouragement, and appreciation.

The message should be emotional and touching, but never manipulative.

Make everything appropriate for a student-teacher relationship.

The writing should feel like it was genuinely written by a thoughtful student, not generated by an AI.

==================================================

DESIGN

Create a premium digital greeting-card experience rather than a generic website.

Visual style:

Warm pastel colors

Soft floral elements

Elegant paper/card textures

Subtle flower and petal animations

Beautiful typography

Rounded cards

Gentle shadows

Smooth transitions

Plenty of whitespace

Cute but sophisticated

Elegant and mature

Not childish

Not overly romantic

Not overloaded with emojis

Use a beautiful combination of cream, soft pink, lavender, peach, and other warm pastel tones.

The website must be fully responsive and look excellent on desktop, tablet, and mobile.

Use smooth scrolling and gentle entrance animations.

Do not use autoplay audio.

==================================================

IMPORTANT: NO LOGIN OR SIGN-UP

Anushka Ma’am must NOT have to create an account, log in, sign up, enter an email, enter a password, or provide any authentication before using the interactive features.

When Anushka Ma’am opens the website, she should be able to immediately:

Read the Teachers’ Day content

Give student ratings

Write/edit/delete her complaints

Submit her report card

Submit complaints

No login page.

No registration page.

No password screen.

No authentication screen.

The website should open directly to the greeting card.

==================================================

DATABASE & DATA PERSISTENCE

The Student Report Card and Teacher’s Complaint Box MUST use a real persistent backend/database.

Use Supabase, Firebase, or another reliable persistent database.

Do NOT use:

localStorage as the primary storage

sessionStorage

temporary browser variables

data stored only in the browser

mock databases

fake data

All submitted information must remain saved permanently in the database.

The information must survive:

Page refresh

Closing the browser

Reopening the browser

Restarting the computer

Opening the website days later

Opening the website from another device

When the website loads, it must automatically retrieve the previously saved information from the database.

==================================================

There is only ONE intended teacher/user:

Anushka Ma’am

She does NOT need to log in.

However, she must have extremely limited access to the website.

Anushka Ma’am should ONLY be able to:

Give ratings in the Student Report Card.

Write a report-card comment.

Submit the report card.

Write complaints.

Delete her own previously submitted complaints.

Submit new complaints.

She must NOT be able to:

Edit the website design

Modify the website content

Only the intended interactive fields and controls should be usable by Anushka Ma’am.
